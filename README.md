# Юридическая практика — одностраничный сайт

Статический сайт находится в папке `dist`.

## Что заменить перед публичным запуском

1. Портрет уже установлен: `dist/assets/team-portrait.jpg`.
2. Мессенджеры: три URL находятся в начале `dist/script.js` в объекте `MESSENGER_LINKS`.
3. Имена, образование, специализации и описания юристов уже заполнены.
4. Город и телефон остаются отмечены квадратными скобками в `dist/index.html`.

Для локального просмотра запустите из папки `dist` любой статический сервер.
