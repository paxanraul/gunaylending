# Юридическая практика — одностраничный сайт

Статический сайт находится в папке `dist`.

## Что заменить перед публичным запуском

1. Портрет: замените `dist/assets/team-portrait-placeholder.svg` на фотографию и обновите `src` в `dist/index.html`, если расширение файла изменилось.
2. Мессенджеры: три URL находятся в начале `dist/script.js` в объекте `MESSENGER_LINKS`.
3. Имена, образование и специализации: найдите квадратные скобки `[...]` в `dist/index.html`.
4. Название команды, город, телефон и политика конфиденциальности: также отмечены квадратными скобками.

Для локального просмотра запустите из папки `dist` любой статический сервер.
